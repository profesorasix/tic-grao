# Instrucciones despliegue script configuración pantalla de aulas

* Copiar fichero _xprofile-aulas.sh_ en /usr/local/bin y dar permisos de ejecución
* Copiar fichero _proyector.desktop_  en _/etc/skel/Escritorio_
* Ejectuar el script desploy-script para copiar los ficheros necesarios en las carpetas Escritorio de los usuarios existentes y futuros.
